# Third-party notices

- This project is a local enhancement layer that works with the official ActivityWatch desktop bundle.
- ActivityWatch itself is **not bundled in this repository**; `scripts/install-base-activitywatch.sh` downloads the latest official Linux release from the ActivityWatch GitHub releases page.
